# Vaccination Mechanism

The immune system detects foreign invaders and produces antibodies that bind to a pathogen and block it from reproducing/functioning. A vaccine exposes the body to a weakened, inactivated, or partial version of a pathogen so the immune system builds those antibodies (and memory cells) in advance, without going through the actual illness.
