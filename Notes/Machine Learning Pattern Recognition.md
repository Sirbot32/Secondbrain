# Machine Learning Pattern Recognition

Machine learning works by taking in large amounts of data (e.g. from the internet), analyzing/comparing it, and building something like the instinctive pattern recognition humans already have — e.g. a human can instantly tell that something shaped like a chair is probably used as a chair; an ML system has to arrive at that same kind of recognition by learning from data instead.
