# Supervised Learning via Labeled Data

AI models can be trained on datasets where humans have manually labeled the correct answer — like how Google's reCAPTCHA had people mark which squares of an image contained part of a traffic light. Splitting the image into squares lets the training process learn where the boundaries of an object are, since each square is labeled individually.
