# AI Hallucination

AI systems can confidently state things that are wrong — they can effectively "convince themselves" of false claims. This is a real, recognized failure mode (commonly called hallucination or confabulation). The precise technical reason this happens is still a gap (see Learning Queue) — it's not fully explained by "lacking instinct."
